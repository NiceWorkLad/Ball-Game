3. Completed Work
------------------
- Basic Ball Game working and tracs score one time
- High score saved in a cookie (ballgame_highscore, kept 1 year), shown as "BEST n" under the board
- Touch screen support (pointer events: mouse, touch, multi-touch) and mobile layout
- Custom cursor (dot + trailing ring, shrinks when clicking; mouse devices only)
- Fixed game speed inconsistencies: physics now runs in fixed 4ms steps on any frame rate, drawn smoothly between steps
- Sideways kick randomness grows with score: none up to 10, ramping to the original 1-or-2 multiplier at 50 (RANDOM_START / RANDOM_FULL in script.js)
- Arrow at the top edge follows the ball when it is above the screen (shrinks/fades with height)
- Forgiving touch: bigger hit area for fingers (1.7x ball radius vs 1.05x mouse), taps count if the ball arrives within 120ms after the finger lifts or was there within the last 80ms, fast swipes count. Tunable via HIT_SCALE / TAP_BUFFER_MS / LATE_TAP_MS in script.js
- Page zoom disabled (pinch, double-tap, iOS gestures) so two-thumb play can't zoom the page; auto-resets if it ever gets zoomed
- Settings screen (button on the start screen, same box as the board): sound on/off + volume, font (6 choices), colour theme (Sunset plus 5 themes from the pool game: Pool Hall, Sketchbook, Pastel, Neon Arcade, Slate). All saved in cookies. Themes are blocks of CSS colour tokens in styles.css
- Hit sounds (Web Audio, random clip of the 8 per hit, unlocked on first tap) with a mute button (saved in a cookie)
- Start, game over and paused screens. Dropping the ball after the first hit ends the game; tap to play again
- Auto-pause when the tab/app goes to the background
