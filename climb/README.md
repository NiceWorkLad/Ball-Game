# Climb to 1000 preview

A copy of the `climb-to-1000` branch, served at `/Ball-Game/climb/` so it runs alongside the current game. Sounds come from `../sounds/`.

Don't edit these files here. Work on the `climb-to-1000` branch, then copy `index.html`, `script.js` and `styles.css` over again (changing the sound path in `script.js` to `../sounds/`). When the climb is finished and merged into `main`, delete this folder.
